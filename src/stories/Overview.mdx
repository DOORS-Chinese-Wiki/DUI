# DUI

这里可以逐个试用 DUI 组件。完整的大厅和设置示例见 [DUI 文档](https://doors-chinese-wiki.github.io/DUI/)。

## 组件怎么组合

只显示图案时用 `Icon`，可点击的大厅入口用 `LobbyIconButton`。`LobbyMenu` 把这些按钮排成一行。鼠标移入时，按钮放大 14%，两侧腾出空间。物品栏槽位放大 25%。

用 `Panel` 做外框，`Space` 和 `Grid` 排内容。滑动条、开关和标签页可以接应用状态，也可以只传默认值。各组件的 Docs 页列出了参数。

## 使用素材

颜色和间距在 `src/styles/tokens.css`，图标名在 `src/components/Icon/assets.ts`。图片、字体和音效的出处见仓库里的 `docs/ASSETS.md`。

打开音效时，用 `<SoundProvider enabled>` 包住组件。组件支持键盘操作，会读取系统的“减少动态效果”偏好。

## MediaWiki

`npm run pack:mediawiki` 生成静态部署包，`npm run pack:miraheze` 生成 Developers Wiki 源码页文件。安装和词条例子见 `docs/MEDIAWIKI.md`。
